❤️ Heart Animation


A mesmerizing heart animation using HTML5 Canvas, CSS, and JavaScript.

📖 Description

This project creates a pulsing heart animation made of colorful particles using the HTML5 <canvas> element. The animation is responsive, works on both desktop and mobile devices, and features smooth particle movement for a glowing effect.

🖥️ Demo

You can view the animation by opening index.html in a modern browser like Chrome, Firefox, or Edge.

📁 Project Structure
heart-animation/
├── index.html      # Main HTML file
├── style.css       # Canvas styling
├── script.js       # Heart animation logic
└── README.md       # Project documentation
⚙️ Technologies Used

HTML5 – Canvas element for drawing

CSS3 – Full-screen layout and styling

JavaScript – Animation, particle system, heart shape calculations

🚀 How to Run

Clone or download this repository:

git clone https://github.com/yourusername/heart-animation.git

Navigate to the project folder:

cd heart-animation

Open index.html in a modern browser.

🔧 Features

Full-screen heart animation

Pulsing and flowing particle effect

Mobile-friendly with reduced particle count for performance

Responsive to window resizing

Colorful particle tracing
